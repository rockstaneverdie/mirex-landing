# WhatchaSay? — логотип

Чёрно-белый логотип расширения-компаньона для просмотра кино в оригинале.

![preview](preview.png)

## Идея знака

- **Строки субтитров** — стопка скруглённых линий, как текст песни в караоке Apple Music.
- **Активная реплика** — центральная линия толще и длиннее остальных; прошлые и будущие строки тоньше («приглушены»).
- **Кнопка Play** — силуэт стопки линий складывается в треугольник, направленный вправо: это видео.
- **Искра над фразой** — ИИ-подсказка, всплывающая прямо над непонятной репликой.

## Файлы

| Файл | Назначение |
| --- | --- |
| `logo-horizontal-black.svg` / `-white.svg` | Знак + надпись, для светлого / тёмного фона |
| `mark-black.svg` / `mark-white.svg` | Только знак, прозрачный фон |
| `icon-black.svg` / `icon-white.svg` | Иконка приложения (скруглённый квадрат) |
| `icon-small.svg` | Упрощённая иконка (3 линии, без искры) для 16 px |
| `png/icon-{16,32,48,128}.png` | Готовые иконки для `manifest.json` расширения |

Надпись набрана Inter Display Bold и переведена в кривые — шрифт устанавливать не нужно.

```json
"icons": {
  "16": "png/icon-16.png",
  "32": "png/icon-32.png",
  "48": "png/icon-48.png",
  "128": "png/icon-128.png"
}
```
